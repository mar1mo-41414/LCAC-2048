# Auto2048 — LiveContainer 用 2048 自走 tweak

[English README →](README-EN.md)

[LiveContainer](https://github.com/LiveContainer/LiveContainer) で動かす **2048** (`com.ketchapp.2048`) の通常ゲームを自動操作する tweak (dylib) です。

- **盤面を自動操作** — 最大 4 手先を探索して方向を選びます。2048 到達は保証しません。
- **速度切り替え** — ボタンの長押しで `x1` / `x2` / `x4` / `MAX` を選べます。
- 対象は 2048 **4.0.8** の通常ゲーム (4×4)。v3 で実機上の自走と 2048 達成を 1 回確認しています。

## ダウンロード

このリポジトリの [`Auto2048.dylib`](Auto2048.dylib) を取得してください。
ゲーム本体・IPA は含まれていません。

## 使い方

1. LiveContainer で 2048 の Tweak フォルダに `Auto2048.dylib` を入れて起動します。旧版がある場合は外してください。
2. 通常ゲームを開くと、右下に `AUTO` ボタンが表示されます (起動時は OFF)。

### AUTO ボタン

| 操作 | 動作 |
| --- | --- |
| タップ | ON / OFF |
| 長押し | 速度切り替え (`x1` → `x2` → `x4` → `MAX`) |

- 速度設定だけ保存され、ON/OFF は保存されません。
- `THINK` は探索中、`PAUSE` はゲーム停止中、`STALE` は盤面変化により探索結果を破棄した状態です。
- 2048 の達成画面では `PAUSE` になります。AUTO が ON のまま「続ける」を押すと、自走が再開します。

## 注意

- 広告やポップアップは完全には検出できません。表示前に AUTO を OFF にし、閉じた後に再開してください。
- 自動操作でスコアやセーブが変わります。必要なら事前にバックアップしてください。
- チャレンジ・対戦、4×4 以外、自動リスタート、自動ポップアップ操作には対応していません。
- ゲームの内部クラス・メソッドを使うため、ゲームや LiveContainer の更新で動かなくなる場合があります。必要な再署名は使用環境の手順に従ってください。

## ビルド

[Theos](https://theos.dev) と iOS SDK が必要です。

```bash
make FINALPACKAGE=1
```

生成された `Auto2048.dylib` は通常 `.theos/obj/` 以下にあります。環境に応じて署名してください。

仕組みの詳細は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)、開発の経緯は [HISTORY.md](HISTORY.md) を参照してください。
